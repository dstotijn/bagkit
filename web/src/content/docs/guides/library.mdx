The `bagkit` command is a thin layer over the `bagkit` crate. Everything it does is available as a library, and you can plug your own code into the same parallel pipeline.

```toml title="Cargo.toml"
[dependencies]
anyhow = "1"
bagkit = { version = "0.1", default-features = false }
```

Without default features the crate reads extracts and writes CSV. Enable `sqlite` or `parquet` for those formats; see [crate features](/installation/#crate-features).

## Stream voorkomens

Inflating and parsing runs on every core; your closure runs on the calling thread. Only documents of the selected types are read.

## Convert on worker threads

For heavier work per voorkomen, implement a `Converter`. It runs on the worker threads, once per voorkomen, and emits items that arrive at your writer closure in document order:

<Code code={countPostcodes} lang="rust" title="examples/count_postcodes.rs" />

`State` holds per-document state, for example to batch items; `begin` creates it and `end` can flush it.

:::caution[Read both parts]
A read happens in [two parts](/concepts/architecture/#two-parts): first woonplaatsen, the relations between woonplaatsen and gemeenten, openbare ruimten and adresseerbare objecten, then nummeraanduidingen and panden. Documents are assigned to parts by name, and documents whose names name no object type are read in the first part whatever they hold. Read both parts, in order, so you see every voorkomen.
:::

## Modules

| Module                        | Purpose                                                                                                                                                                        |
| ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `extract`                     | Read the current voorkomens of selected object types in parallel                                                                                                               |
| `xml`                         | The typed voorkomens: `Locality` (woonplaats), `PublicSpace` (openbare ruimte), `Address` (nummeraanduiding), `AddressableObject` (adresseerbaar object) and `Building` (pand) |
| `tables`, `address_list`      | Shape voorkomens into rows                                                                                                                                                     |
| `dataset`                     | Table definitions, values and formats                                                                                                                                          |
| `output`, `sqlite`, `parquet` | Write rows                                                                                                                                                                     |
| `convert`                     | Run all of the above                                                                                                                                                           |
| `query`, `api`, `server`      | Look adressen up in SQLite output and serve the HTTP API                                                                                                                       |
